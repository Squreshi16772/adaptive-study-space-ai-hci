Core concept

Adaptive UI

An adaptive user interface changes its presentation, navigation, content, or interaction behavior at runtime in response to information about the user, task, or context.

In this demo, concise and detailed are two alternatives. The interface uses feedback to estimate which alternative is more useful for the current learner.

Intelligent UI

Intelligence supports interaction

An intelligent user interface applies computational intelligence to make interaction more effective, natural, or supportive.

An adaptive UI is often an intelligent UI when it uses a model or learning method. However, not every intelligent UI changes its presentation, and a rule-based adaptive UI need not use machine learning.

Design safeguard

Adapt with consent and recourse

Good adaptation is visible, reversible, and easy to override. Users should be able to understand what changed and correct an inaccurate inference.

The buttons above provide a direct override. The explanation panel shows the stored reward counts, and reset removes all locally stored learning.
